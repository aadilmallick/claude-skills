# Package verification

The plugin is an instruction-and-support-file package. It declares one portable skill and no MCP server, external app dependency, or remote service.

Eight workflow tests passed against a synthetic fixture: assembly with intact code and included source, minimum-depth rejection, draft rejection, unchanged-starter rejection, broken-anchor detection, path-escape rejection, missing-file rejection, and unclosed-code-fence rejection. These are structural behavior tests, not a claim that generated textbooks are automatically correct.

The companion starter was served locally and opened in a browser. Its Canvas output was visually inspected. Moving the interpolation control to 1 produced 10.00 from endpoints 2 and 10; Reset returned to fraction 0.35 and result 4.80. The catalog/module-path check also passed. Future subject-specific experiments require their own runtime, numerical, and visual verification.

Manifest JSON, template JSON, skill YAML frontmatter, optional agent YAML, referenced supporting files, Python syntax, and JavaScript syntax are checked during package preparation. The final archive is inspected separately before upload. No learner's textbook, source extraction, account identifier, credential, or dependency installation is included.

The assembler and validator intentionally do not certify teaching quality, mathematical truth, all Markdown extensions, accessibility across all platforms, or universal runtime support. Their limits are stated in the skill and reference documents.
