# Animation Psychology

Never ask:

"What should animate?"

Ask:

"What should users feel?"

---

Trust

Use:

- slower easing
- calmer transitions
- fewer moving objects

---

Intelligence

Use:

- diagnostics
- system indicators
- updating metrics
- structured movement

---

Wonder

Use:

- parallax
- depth
- scaling environments

---

Velocity

Use:

- fast transitions
- low travel distance

---

Power

Use:

- larger movement
- dramatic entrances

---

# Living System Principle

The page should always imply:

something is happening

Techniques:

- status indicators
- metric updates
- heartbeat pulses
- scrolling logs
- subtle ticker feeds

Users associate activity with capability.
